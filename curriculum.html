Technical Foundations

The computing, engineering, and platform groundwork everything else is built on.

13 courses

A01 / Computing Fundamentals

How a computer actually works: architecture, CPU, memory, storage, binary, operating systems, processes, and the terminal.

A02 / Computer Science

The theory behind programs: programming fundamentals, data structures, algorithms, complexity, and computational models.

A03 / Mathematics for Computing and AI

The math you'll actually use: discrete math, logic, linear algebra, probability, and statistics.

A04 / Developer Tooling and Workflow

Working like an engineer: Git, the shell, editors, debugging, reading documentation, and package management.

A05 / Software Engineering

Building software that lasts: languages, architecture, APIs, testing, version control, and deployment.

A06 / Web Platform

The deep web track: HTML, CSS, JavaScript, TypeScript, browsers, React, and Next.js, built from the original in-depth guide.

A07 / Apple Platforms

Building for Apple: Swift, SwiftUI, UIKit, AppKit, Xcode, and shipping to iOS and macOS.

A08 / Systems and Infrastructure

How technology connects and runs: networking, Linux and OS administration, cloud, hardware diagnostics, and reliability.

A09 / Security and Identity

Keeping systems safe: authentication, authorization, cryptography basics, threat modeling, and secure design.

A10 / Data and Databases

How information is modeled, stored, and retrieved: SQL, PostgreSQL, indexing, pipelines, and search.

A11 / Design Engineering

Where design meets code: interaction and visual design, typography, accessibility, prototyping, and design systems.

A12 / Artificial Intelligence

How machines learn: machine learning, neural networks, language models, embeddings, retrieval, inference, and evaluation.

A13 / Embedded and Hardware

Software that touches the physical world: microcontrollers, firmware, sensors, and hardware interfaces.

Planning/Track B

Agent Engineering

How agents actually work, from models and tools to loops, memory, safety, and production.

16 courses

B01 / Agent Engineering Foundations

What an agent really is: model vs. agent, functions vs. workflows vs. agents vs. autonomy, and when not to build an agent at all.

B02 / How Language Models Work

Just enough model internals to reason about agents: tokens, context windows, sampling, inference, model limits, and why models hallucinate.

B03 / Working with Model APIs

Talking to models as software: requests, messages and roles, streaming, structured output, rate limits, cost, and choosing models.

B04 / Prompting and Instructions

Designing behavior in language: system prompts, roles, examples, specifications, and writing instructions an agent reliably follows.

B05 / Tools and Function Calling

How agents act on the world: tool schemas, the function-calling cycle, tool registries, MCP, and designing tools a model uses well.

B06 / The Agent Loop

The core runtime: observe, decide, act, repeat, plus stopping conditions, retries, error handling, and building the loop yourself.

B07 / Context, State, and Memory

How agents remember: context engineering, conversation state, short- and long-term memory, summarization, and persistence.

B08 / Retrieval and Knowledge

Giving agents knowledge: embeddings, vector search, RAG, chunking, and grounding answers in real sources.

B09 / Planning and Reasoning

How agents break down work: task decomposition, plan-and-execute, reflection, self-correction, and reasoning models.

B10 / Multi-Agent Systems

When one agent isn't enough: orchestrators and subagents, handoffs, delegation, and the real costs of coordination.

B11 / Safety, Guardrails, and Permissions

Keeping agents in bounds: approvals, human-in-the-loop, sandboxing, prompt injection, untrusted content, and least privilege.

B12 / Evaluation and Observability

Knowing if an agent works: evals, test sets, tracing, logging, token and cost tracking, and debugging agent behavior.

B13 / Agents in Production

Running agents as real software: async jobs, queues, scheduling, durable workflows, databases, deployment, and cost control.

B14 / Agent Interfaces and UX

Designing for people and agents together: chat and beyond, streaming UI, approvals, trust, and showing what an agent is doing.

B15 / Frameworks and the Ecosystem

Once you know the machinery: OpenAI Agents SDK, Vercel AI SDK, LangGraph, MCP servers, and when a framework helps or hides.

B16 / Capstone: Build Your Own Agent

A from-scratch research agent in TypeScript, grown step by step: tools, loop, memory, scheduling, a database, and a UI.
