# D10 AI Interfaces

Group: AI & Tools · Wk 19–20

Design and build how AI products feel: streaming, agent steps, approvals.

## Course output
3 · AI chat/agent interface

- Streaming chat with a visible thinking state
- Tool-call steps as an expandable timeline
- Approve / reject gate before a risky action
- Cost or token meter (nod to Basehull kill switch)

**Why:** Every AI company needs this designed well, and it links to Basehull.

## Weekly rhythm
- Mon: Template teardown
- Tue–Thu: One state per day: stream, tool step, approval
- Fri: Motion polish on state changes

## Done when
- [ ] Streaming works
- [ ] Agent steps visible
- [ ] Approval gate blocks until approved
- [ ] Live demo + case study
