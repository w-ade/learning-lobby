# D02 CSS Craft & Layout Fluency

Group: Craft · Wk 3–4

Build any layout from a design without fighting CSS.

## Course output
Warm-up: 5 layout rebuilds (feeds project 10)

- Pick 5 sites you admire
- Rebuild one hero or section each, responsive
- No component libraries

**Why:** Pixel-faithful layout is the floor every studio assumes.

## Weekly rhythm
- Mon: Read one layout topic
- Tue–Thu: Rebuild one real site section a day from a screenshot
- Fri: Compare against original, note gaps

## Done when
- [ ] 5 rebuilds deployed
- [ ] Comfortable with Grid areas and container queries
- [ ] Fluid type scale saved as a snippet
