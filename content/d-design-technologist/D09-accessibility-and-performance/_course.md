# D09 Accessibility & Performance

Group: Systems · Wk 17–18

Make everything you've built usable by everyone and fast.

## Course output
Audit pass on 1, 2, 5, 6

- Keyboard + VoiceOver on every interactive piece
- Before/after Lighthouse scores
- Write findings into each case study

**Why:** Separates prototype builders from people a team can ship with.

## Weekly rhythm
- Mon: Audit one past project
- Tue–Thu: Fix + keyboard-only test
- Fri: Screen reader pass (VoiceOver)

## Done when
- [ ] All projects keyboard-usable
- [ ] Perf 90+ everywhere
- [ ] Findings documented
