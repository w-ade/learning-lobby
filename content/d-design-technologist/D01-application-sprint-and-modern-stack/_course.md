# D01 Application Sprint & Modern Stack

Group: Launch · Wk 1–2

Ship Little Plains-ready material in 10 days while locking in the Next.js/React/TS baseline.

## Course output
7 · One-day rapid prototype sprint

- Write a fake client brief (e.g. a studio event microsite)
- Ship a working Next.js prototype in one day on Vercel
- Log every AI step: prompts, what you kept, what you rewrote
- Publish a 1-page notes write-up

**Why:** It's literally the job, and it doubles as your Little Plains note on how you use agentic tools.

## Weekly rhythm
- Mon–Tue: Resume + pick 3 portfolio pieces (oklab, glide, dev-lines)
- Wed–Thu: Write the agentic-tools note from real sessions
- Fri: Ship the 1-day sprint (project 7)
- Wk 2: Polish, send Little Plains, then Next.js Learn chapters

## Done when
- [ ] Resume updated (Menlo/mono accents, real text PDF)
- [ ] Portfolio links to oklab, glide, dev-lines
- [ ] Agentic-tools note written
- [ ] Sprint prototype live + notes published
- [ ] Little Plains application sent
